★ Widget's Path ★

Widget needs a charge!

Tap the arrows to build a program. Each arrow moves Widget one square. Press Run and he follows it, step by step. Eight puzzles, then Widget is fully charged.

Charged up!

Fully charged! 🔋

Widget's whole story is in Capitol Hill Coding, one of our learning games.

    Eight puzzles, about 5 minutes.

    HOW.TXT

    How to play

    • Each arrow block moves Widget one square that way.
    • Line up blocks, then press Run. Widget does them in order.
    • Boxes and puddles are in the way. Widget stops with a bonk, and the block that bumped turns red. Fix it and run again.
    • Gears ⚙ have to be picked up before the battery will charge.
    • Tap a block in your program to take it out.
    KEYS.TXT

    With a keyboard

    ↑ ↓ ← → add blocks.

    Backspace takes the last block back out.

    Enter runs the program.

    This is what programmers do: plan the steps, run them, find the bug, fix it.
